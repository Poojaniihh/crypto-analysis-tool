
# Crypto Analysis AI Tool

An AI-powered cryptocurrency analysis tool that uses real-time market data and AI to analyze and compare cryptocurrencies.

### Features

- Analyze multiple cryptocurrencies.
- Identify market sentiment (Bullish, Bearish, Neutral).
- Generate short-term market predictions.
- Compare cryptocurrencies and identify potential market opportunities.
- Display key market factors and AI-generated insights.

### Technologies Used

- Python
- FastAPI
- HTML, CSS, JavaScript
- OpenRouter API (Llama 3.3 70B)
- CoinGecko API
- Pydantic
